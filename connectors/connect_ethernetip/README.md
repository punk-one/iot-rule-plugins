# connect-ethernetip

Preview: EtherNet/IP explicit unconnected Logix tag services 0x4C/0x4D, RegisterSession and bounded CPF parsing. Direct UCMM or optional one-hop backplane slot; one TCP/session per batch (up to 128 scalar tags), serialized per resource and package limit 8 sessions. Pure Go and owned absolute socket deadlines/cancellation. Bool, Int/Uint16/32/64, Float32/64; 64-bit values use exact decimal strings. Symbolic members and one-dimensional index per member; no UDT/string/whole-array/fragmented read, PCCC/SLC/MicroLogix, implicit I/O or CIP Safety claim. Device type/model must support selected services. No auto-retry, partial write outcomes are unknown. Socket close ends the session; no persistent connection/ForwardOpen. [Rockwell data access manual](https://literature.rockwellautomation.com/idc/groups/literature/documents/pm/1756-pm020_-en-p.pdf). Loopback wire tests are not real PLC acceptance.
