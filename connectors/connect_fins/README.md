# connect-fins

CS/CJ/CP memory-area codes, FINS UDP or TCP; explicit source/destination node and network IDs. TCP assigned nodes must match configured IDs. One session per batch, merged contiguous/overlapping word reads (128 words) or bits within one word. Supports DM/CIO/W/H/A; auxiliary writes are disabled. Protocol 0-based word address plus bit 0..15. Bool, Int/Uint16, Int/Uint32 and Float32; 32-bit byteOrder is mandatory to avoid silently guessing PLC word layout. FINS response routes, SID, command and end code are checked. Absolute deadline/cancellation includes serialization; no automatic writes retries. Per-batch writes can partially succeed. End code success is not evidence a physical action completed. No HostLink/CV/EM-bank/remote-control claim. UDP has no transport reliability; all lost/invalid replies fail explicitly. [OMRON W342](https://assets.omron.eu/downloads/latest/manual/en/w342_cs_cj_cp_nsj_communications_commands_reference_manual_en.pdf?v=9). Real model/timing acceptance remains pending.
