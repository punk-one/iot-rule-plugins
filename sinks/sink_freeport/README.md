# sink-freeport

Explicit standalone raw transport write, independent from poll framing. Input {device_code,expires_at(ms),data:{raw_base64}}; exact target, unexpired deadline and bounded base64 required. Resource allow_write is separately required. TCP/serial/UDP Connector rechecks absolute expiry after queueing and enforces it during I/O. A send may partially succeed, never transparently retried; local send success is not device processing or physical completion. Buffered inputs are rejected because no peer/business ACK exists. Use command-guard upstream for persistent claims and a separately verified protocol for command outcomes. Default max65507 fits UDP; TCP/serial may explicitly allow up to1MiB. No automatic protocol encoding/checksum or invented response acknowledgement.
